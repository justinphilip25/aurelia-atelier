# Aurelia-Atelier

A premium, responsive static website concept built with HTML, CSS and vanilla JavaScript.

## Local preview
Open index.html in a browser, or run a local static server from this folder.

## Deploy to Cloudflare Pages
1. In Cloudflare Dashboard, open **Workers & Pages**.
2. Choose **Create application** → **Pages** → **Connect to Git**.
3. Select this GitHub repository.
4. Framework preset: **None**.
5. Build command: leave empty.
6. Build output directory: / (the repository root).
7. Save and deploy.

No build step or environment variables are required.

## Customize
- Replace hello@example.com in index.html with your real contact email.
- Edit colors and layout in styles.css.
- Update copy and sections in index.html.
